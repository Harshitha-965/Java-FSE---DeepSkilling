Purpose:

------------------------------------------------------------

3. tsconfig.app.json
Purpose:
Contains TypeScript compiler settings for the Angular application.

------------------------------------------------------------

4. package.json
Purpose:
Contains project details, npm scripts and required dependencies.

------------------------------------------------------------

5. src/main.ts
Purpose:
Entry point of the application. Bootstraps the standalone Angular application.

------------------------------------------------------------

6. src/app/app.config.ts
Purpose:
Registers application-wide providers such as routing and HttpClient.

------------------------------------------------------------

7. src/app/app.ts
Purpose:
Root component of the Angular application.

------------------------------------------------------------

8. src/index.html
Purpose:
Main HTML page where Angular renders the application.
